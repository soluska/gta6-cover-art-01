**Neon Vice** — a GTA-style cover art studio that runs entirely offline in the browser. Drop in any photo, add a caption, and get the iconic multi-panel cover / loading-screen look with a Vice City neon-sunset grade, exported as a shareable PNG. Four cover layouts (Classic Six, Mosaic Eight, Split Strip, Wide Story), a per-pixel colour lab (split-tone LUT grades, duotone ink ramp, poster-pop cutout), code-drawn scene panels (retro sun, skyline, muscle car, speedboat, chopper, flamingos), display typography with poster credits, film grain and vignette. No AI-generated images, no downloaded assets, no network at runtime — every visual is computed or drawn in code from the user's own photo.

## Run it

```sh
node serve.ts   # serve the app locally
node main.ts    # build the entry dossier
```
